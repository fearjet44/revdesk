# T1.2 — Prerequisites screen

**Task:** T1.2 · **Track:** T1 Platform · **Size:** S · **Branch:** `t1/prerequisites-screen` · **Needs:** W0 and T1.1 merged
**Read first:** `AGENTS.md`, `docs/runbook/desktop.md` (the verified brew/winget lines), `server/tools.ts` (`doctor()`, `ToolStatus`), `scripts/tools-check.ts`, `server/plugin.ts` (`createApiHandler`, the `config` routes), `src/App.tsx`.

## Goal

A new user (often on Windows) installs Revdesk without qpdf or poppler and finds out only when a PDF fails. W0 already built `doctor()`. This task shows its answer: a **Prerequisites** screen that lists each tool, whether it was found, what it is for, and the one line that installs it on this OS. It opens by itself once, at first run from the home page. After that, a banner links to it whenever a tool is missing; it never redirects again.

## Done when

- [ ] **Install lines** live in `server/tools.ts`: a pure `installHint(name, platform)` returning the line for `darwin` (brew), `win32` (winget), and `linux` (apt). Use only the IDs already verified in `docs/runbook/desktop.md`:
  - macOS: `brew install node git qpdf poppler`; Chrome is a download from google.com/chrome (say so, no command).
  - Windows: `winget install Git.Git`, `QPDF.QPDF`, `oschwartz10612.Poppler`. Edge ships with Windows, so chrome has no line.
  - Linux: `sudo apt install git qpdf poppler-utils chromium` (name the package per tool; poppler covers `pdftotext`/`pdfinfo`/`pdffonts`).
  `doctor()` gains `platform` and each `ToolStatus` gains `install: string | null`. Keep existing fields and their meaning.
- [ ] **API** (`server/plugin.ts`, additive): `GET /api/doctor` → `200 doctor()`. It must answer **even when no library resolves**: handle it in `createApiHandler` before `resolveLibraryRoot` / `new Repo`, as a small early branch. Nothing else in that function changes.
- [ ] **CLI** (`cli/revdesk.ts` dispatch, additive): `revdesk doctor` prints one line per tool (`ok`/`missing`, name, path or install line) and `--json` prints the object. Exit `0` when all found, `5` when any is missing. One usage line next to its siblings.
- [ ] **Screen** (`src/components/DoctorView.tsx`, new; `src/api.ts` + `src/App.tsx` additive):
  - Route `/prerequisites`. A table: tool, needed for, found path (or "Not found"), version, install line with a **Copy** button. A **Check again** button refetches.
  - A short note under the table: "Revdesk does not install these for you. Install them, then Check again." Plain words, no Git words in UI text (`git` the tool name is the one exception, shown as the tool's name only, in the table's tool column).
  - In `DeskApp`: fetch `/api/doctor` once on load. If `ok` is false, show a slim banner on every page: "Some tools Revdesk needs are missing. **See prerequisites**", linking to `/prerequisites`. If the doctor call itself fails, show nothing (the dev server may be older).
  - **First run:** if `localStorage['revdesk.prereqsSeen']` is unset (wrap reads/writes in try/catch), navigate to `/prerequisites` once and set it. The banner is the "whenever a tool is missing" half.
  - A **Prerequisites** link in the mast, next to Config.
  - Styling with existing classes and theme variables in `src/index.css` (named exception: append a small block of `.doctor-*` rules; do not edit existing rules).
- [ ] **Tests:** extend `scripts/tools-check.ts`: every tool has an install line or a documented `null` for each platform; `doctor().platform === process.platform`; the shape has `install`. Add a check that `GET /api/doctor` answers with the library env pointed at a non-existent dir (call `createApiHandler` with a fake req/res, or start the standalone server on a free port; pick whichever is shorter).
- [ ] `npx tsc -b`, `npm run lint`, `npm run test:md`, `npm run build && npm run build:server` pass.
- [ ] Manual: run the desk with `PATH` trimmed so qpdf is not found (or `REVDESK_QPDF=/nope`), confirm the banner, the screen, the copy button, and that Check again flips to ok after restoring it. Screenshot it with Playwright and attach the description (not the image) to the PR.
