# T3.4 — Editors know the manual before they load the text

**Task:** T3.4 · **Track:** T3 Editor & figures · **Size:** S · **Branch:** `t3/editor-loads-once` · **Needs:** T3.2 merged (same files; T3 runs serially)
**Read first:** `AGENTS.md`, `docs/plan/figures.md` (Editor and Issued), `src/schema/extensions.ts` (`buildEditorExtensions`), `src/schema/figure-view.ts`, `src/components/SectionEditor.tsx`, `IssuedSection.tsx`, `ManagedSection.tsx`.

## Goal

`buildEditorExtensions({ manualId })` is memoized on `manualId`, and `useEditor(…, [extensions])` rebuilds the editor when it changes. `SectionEditor` and `IssuedSection` learn the manual id only **after** they have loaded and set the section text, so each open builds the editor twice and loads the text twice. Between the two builds:

- a figure shows "Figure missing" for a moment, and
- anything typed in that window is thrown away.

Found in T3.1/T3.2 (PRs #18, #21).

## Done when

- [ ] Each of the three views has its manual id **before** it creates the editor that shows the text, and builds that editor once per section opened.
  - `SectionEditor`: get the change's manual first. Use whatever the working-copy load already returns, or `api.reviewSection` / the change record before `workingSection`. Then load the text into an editor built with that id.
  - `IssuedSection`: same, from the issue → manual.
  - `ManagedSection`: has it from the route already; confirm it builds once.
  - Until the id is known, render the existing loading state, not an editable empty editor.
- [ ] The editor stays non-editable until the text is in, so no keystroke can land in a throwaway editor.
- [ ] No change to `figure-view.ts` beyond what this needs. The node view keeps taking `manualId` from the extension options; don't parse it from the URL.
- [ ] A test. Either:
  - a Playwright script `scripts/editor-load-check.ts` (not wired into `test:md`) that opens a working section containing a figure and asserts `/api/manuals/<id>/figures/…` is the **first** image request (no `/api/manuals//figures/…`) and that `workingSection` is fetched once; or
  - if that's too heavy, a counter of editor creations exposed only in dev, checked by hand. Say which in the PR.
- [ ] `npx tsc -b`, `npm run lint`, `npm run test:md`, `npm run test:review`, `npm run test:slice10` pass.
- [ ] Manual check: open a working section with a figure and type immediately. No missing flash, no lost characters.
