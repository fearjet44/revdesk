# T3.2 — Editor figure insert

**Task:** T3.2 · **Track:** T3 Editor & figures · **Size:** M · **Branch:** `t3/figure-insert` · **Needs:** T3.1 merged (same files; T3 runs one task at a time)
**Read first:** `AGENTS.md`, **`docs/plan/figures.md`**, `docs/handoffs/T3.1-FIGURE-SCHEMA.md`, then what T3.1 shipped: `server/figures.ts`, the figure routes in `server/plugin.ts`, the `Figure` node in `src/schema/extensions.ts`, `src/schema/figure-view.ts`, and the toolbar in `src/components/SectionEditor.tsx`.

## Goal

T3.1 made a figure a block that parses, shows, and prints. An author still can't add one from the desk. This task adds **Figure** to the editor toolbar: pick a file, upload it, insert the node; then edit the caption, pick a width, or replace the image.

## Done when

- [ ] `src/api.ts` (additive): `uploadFigure(manualId, file: File) → { src, bytes, existed }`, base64 in the JSON body, same convention as the ingest upload.
- [ ] **Toolbar** (`SectionEditor.tsx`): a **Figure** button next to the other block buttons. It opens a hidden `<input type="file" accept="image/png,image/jpeg,image/gif,image/svg+xml,image/webp">`. On pick: upload, then insert `{ type: 'figure', attrs: { src, caption: '', width: '100%' } }` at the selection as a block (split the paragraph if mid-text; never inline). Focus the caption afterwards.
  - Refused types or files over 10 MB: show the server's message in the editor's existing error spot. Check size client-side first so a 40 MB file isn't base64'd.
  - Disabled while uploading and when the editor isn't editable.
- [ ] **Width menu** in the figure node view when editable: `25% · 50% · 75% · 100%`, writing `width` with `updateAttributes`. Read-only views show no controls.
- [ ] **Replace image** in the node view when editable: same picker and upload, then `updateAttributes({ src })`. The old file stays on disk (write-once; never delete).
- [ ] **Caption** stays plain text (no marks), as T3.1 built it. Enter in the caption moves the cursor below the figure instead of inserting a newline.
- [ ] Drag-and-drop or paste of an image file into the editor does the same upload + insert. Pasted HTML `<img>` with a URL is **not** fetched; it stays dropped as today.
- [ ] Working copy only: the button exists only on the change desk's editable section editor. Issued and managed views stay read-only.
- [ ] **Tests:**
  - Extend `scripts/figures-check.ts`: after a simulated insert (editor JSON with a figure + attrs set by the width menu), `serializeBody` emits `{width=50%}` and round-trips; replacing `src` leaves the old file in place.
  - A Playwright check is welcome but not required. If you add one, put it in `scripts/figures-ui-check.ts` and do not wire it into `test:md`.
- [ ] `npx tsc -b`, `npm run lint`, `npm run test:md`, `npm run test:review`, `npm run test:slice10` pass.
- [ ] Manual: on a scratch library copy, open a change, insert a PNG, caption it, set 50%, replace it, submit, and confirm the reviewer diff shows the figure line change and the PDF prints it. Say in the PR what you saw.
