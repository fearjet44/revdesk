# T1.5 — Prerequisites screen opens every launch on the desktop

**Task:** T1.5 · **Track:** T1 Platform · **Size:** S · **Branch:** `t1/first-run-desktop` · **Needs:** T1.4 merged (same files)
**Read first:** `AGENTS.md`, `docs/handoffs/T1.2-PREREQUISITES-SCREEN.md`, `src/App.tsx` (`firstPrereqsVisit`), `src-tauri/src/lib.rs` (`start_sidecar`), `server/standalone.ts` (`--port`, default `0`).

## Goal

The desktop shell starts the sidecar on port `0`, so every launch gets a new loopback origin. `localStorage` is per origin. As a result, `revdesk.prereqsSeen` is empty on every launch and the Prerequisites screen takes over the desk **every time the app opens**. Found while writing T1.3 (PR #22).

**Decision:** stop depending on a remembered flag. When the desk loads at `/`, it goes to Prerequisites **only when `doctor().ok` is false**. When every tool is found, the desk opens normally and the screen stays one click away in the mast. The banner is unchanged. This fixes the desktop and is also the behaviour a returning user wants in the browser.

It happens once per page load; **Check again** never navigates.
