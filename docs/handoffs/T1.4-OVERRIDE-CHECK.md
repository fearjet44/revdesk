# T1.4 — A tool override that points nowhere is not "found"

## Goal

`envOverride()` returns `REVDESK_CHROME`, `REVDESK_QPDF`, `REVDESK_GIT`, or `REVDESK_POPPLER_DIR/<tool>` without checking that the file exists. So a stale or mistyped override shows as **found** on the prerequisites screen, and the failure only shows up later as an ENOENT in the middle of a PDF render. Found in T1.2 (PR #17).

**Decision:** an override is the user's explicit choice. When it points at a missing file, Revdesk **does not** quietly fall back to PATH. It reports the tool as missing and names the override that is wrong, so the user fixes the setting that is actually in effect.
