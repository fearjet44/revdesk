## Goal

Real manuals are full of bullet lists. Today the schema has none. The parser doesn't recognize `- ` items, and the editor turns `bulletList` off, so an imported list would collapse into one run-on paragraph (`- a - b - c`). T2.2's Word import needs a bullet node to write into. Steps (ordered lists) already work; bullets should work the same way and mix with them.

## Done when

- [ ] **Markdown:**
  - A line `- text` at the current indent is a bullet item.
  - Nesting uses the same `STEP_INDENT` (3 spaces) as steps, so a bullet can contain nested bullets **or** steps and a step can contain nested bullets, up to `STEP_MAX_DEPTH` total.
  - `isBlockStart` recognizes `- ` at column 0, so a bullet line ends the paragraph above it.
  - Continuation lines of an item follow the same indentation rule steps use.
- [ ] Generalize rather than copy: turn `parseOrderedList` into one list parser that takes the item marker kind and recognizes either marker at the nested indent. The same goes for `serializeOrderedList` → a list serializer that writes `- ` or `N. ` per list. The flat `bulletList` serializer in `serializeBlock` goes away.
- [ ] Round-trip is exact: `parseBody(serializeBody(doc))` equals `doc` for flat bullets, nested bullets, bullets inside steps, steps inside bullets, and bullets with **bold**/*italic*/<u>underline</u> text.
- [ ] Unchanged:
  - `-` in the middle of a line, `--`, and `-text` (no space) stay paragraph text.
  - A line starting with `- ` **inside** a callout fence works as a bullet inside the callout.
  - Every existing leaf in `data/` and `fixtures/` parses and serializes byte-identically. Prove it in the test by round-tripping all of them.
- [ ] **Editor:**
  - Turn on StarterKit `bulletList`.
  - Add a toolbar **Bullets** button next to the steps button in `SectionEditor.tsx`, using the same pattern.
  - `Tab`/`Shift-Tab` already sink and lift `listItem`; check they work in bullets and in mixed nesting.
  - Paste of a bulleted list from Word or a browser yields bullets.
- [ ] **Paper:**
  - Print and Issued render `<ul>` with a plain disc → circle → square marker by depth, spaced like steps.
  - Steps keep their step markers (`stepMarkerCss`).
  - CSS goes in `src/index.css` and the print stylesheet in `server/print.ts`.
- [ ] **Tests:** extend `scripts/steps-check.ts` (or add `scripts/bullets-check.ts` and append it to `test:md`) with the round-trip cases above and the "all existing leaves byte-identical" sweep.
- [ ] `npx tsc -b`, `npm run lint`, `npm run test:md`, `npm run test:slice10` pass.
- [ ] Manual check on a scratch library copy: write a nested bulleted list in the editor, write it to disk, reload, then check Issued and the PDF. Say what you saw in the PR.
