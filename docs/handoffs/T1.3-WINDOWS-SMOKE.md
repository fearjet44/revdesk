**Task:** T1.3 · **Track:** T1 Platform · **Size:** S · **Branch:** `t1/windows-smoke` · **Needs:** T1.1 and T1.2 merged; T1.4 merged or in review (the checklist names its override message)

## Goal

Nobody has run Revdesk on a real Windows machine yet. The Windows user is not a developer. This task writes the **one page they follow** from download to an Issued PDF, with a place to write down what they saw. The agent writes the checklist; the Windows user runs it; findings come back as new fix tasks.

## Done when

- [ ] New `docs/runbook/windows-smoke.md`. Plain words, numbered steps, one action per step, and an **Expected:** line under each. No Git words (§3), except the tool name `git` in the prerequisites table. Sections:
  1. **Before you start**: Windows 10/11, about 30 minutes, a practice library only (the in-repo `data/` sample or a scratch copy). **Never a company manual.**
  2. **Install**: download the CI artifact, SmartScreen "More info → Run anyway", where it installs, and launch from the Start menu. Expected: no console window behind the app.
  3. **Prerequisites**:
     - First launch lands on the Prerequisites screen. Write down which rows say Not found.
     - Run the winget lines from `desktop.md`, close and reopen Revdesk, and press **Check again**. Expected: all rows ok and no banner.
     - **Bad override**: set `REVDESK_QPDF` to a wrong path, reopen, and read the message; then unset it.
  4. **Open the practice library**: find GOML in the rail, open a section, and confirm the text shows with Windows line endings (no stray `\r`, no blank-line doubling).
  5. **Make a change**:
     - Start a change, edit one section (add a sentence, a bullet, a nested step), and write the section.
     - Then the reviewer side: open the change, see the line diff, approve.
     - Each step has an Expected line using the desk's own button labels. Read them from the components; don't guess.
  6. **Figure**: insert a PNG with the toolbar Figure button (T3.2; if it hasn't merged, mark the step "skip until T3.2"), caption it, write the section, and confirm it shows.
  7. **Issued PDF in Edge**: open Manual PDF for the regulator and reference kinds, download one, and open it from Downloads. Expected: the page stamp and the watermark are there, and the figure prints.
  8. **CLI** (optional, PowerShell): from the install or a source checkout, `revdesk doctor` exits 0. Give the exact command for the installed app if one exists. If there isn't one, say "source checkout only" and give the `node --experimental-strip-types cli\revdesk.ts doctor` form.
  9. **Report back**: a fill-in table (step, pass/fail, what you saw). Screenshots are welcome, of the practice library only. Where to send it: paste it into a new GitHub issue titled `Windows smoke <date>`.
- [ ] Every UI label, button name, and message the checklist quotes is checked against the current source (grep for it). List the greps you ran in the PR.
