# T2.1 — Practice mode + ingest guards

**Task:** T2.1 · **Track:** T2 Ingest · **Size:** S · **Branch:** `t2/practice-mode` · **Needs:** W0 merged
**Read first:** `AGENTS.md` (§3, the "company manuals never enter this repo" rule), `docs/plan/ROADMAP.md`, `server/ingest.ts` (`applyIngest`, `matchGoldCatalog`, `writeCatalog`, `writeBaseline`), `scripts/slice7-ingest-check.ts`.

## Goal

Ingest always writes lorem today. That was a test-era safety rail. The operator now has permission to bring the company's real manuals into a **private** library, so:

- **Source text is the default.** This task adds the switch and the guards. The actual text import is T2.2 (.docx) and T2.3 (PDF). Until those land, choosing source text stops with a clear "not built yet" message.
- **Lorem becomes "practice mode,"** an explicit choice for OSS users who want to try Revdesk on a manual from the wild without storing its prose.
- **Two guards:**
  1. Real text never goes into the in-repo sample library (`<repo>/data`).
  2. Ingest never silently overwrites a manual that already exists.

## Done when

- [ ] `IngestApplyInput` gains `bodies?: 'source' | 'practice'` (default `'source'`) and `replace?: boolean` (default `false`). `IngestApplyResult` gains `bodies`.
- [ ] `applyIngest` does these checks **in this order**, before writing anything:
  1. **Sample-library guard.** `bodies === 'source'` and `dataRoot` resolves to `path.join(ROOT, 'data')` or inside it → `RepoError(4, 'This is the practice library that ships with Revdesk. Open your own library folder to bring in a real book, or choose a practice copy.')`
  2. **Overwrite guard.** `manuals/<id>/` already exists and `replace` is false → `RepoError(4, 'A manual with id <id> is already in this library. Choose replace to bring it in again.')`
  3. **History guard.** `replace` is true but the manual has history: any `control/changes/*.yaml` with `manual: <id>`, any `control/trs/*.yaml` for it, or any `control/issues/*.yaml` for it whose `change` is not `CHG-BASELINE` → `RepoError(4, 'Manual <id> has changes or launches since it was brought in. Replacing it would rewrite controlled history; start a revision instead.')`
  4. **Not built yet.** `bodies === 'source'` → `RepoError(5, 'Bringing in the source text is not built yet. Choose a practice copy for now.')`. T2.2 replaces this line.
- [ ] Gold-catalog substitution (`matchGoldCatalog` → `loadCatalog`) happens **only** when `bodies === 'practice'`. A real book must never be swapped for the sanitized Nimbl map.
- [ ] `replace: true` with no history removes `manuals/<id>/sections/` before writing, so no stale leaves survive. Leave `theme.yaml` alone if present; `writeCatalog` already skips it.
- [ ] CLI: `revdesk ingest <file> [--practice] [--replace] [--out dir]`. Usage and help text are updated. `ingest scaffold` stays practice-only and unchanged.
