## Goal

This is **the critical path to dogfood.** The operator needs to make real corrections to the company's manuals soon. Each manual exists as Word, or as a PDF that the operator converts to Word with Acrobat (Export PDF → Word, "Retain Flowing Text"). This task brings a `.docx` into a private library as Revdesk leaves **with the real text**, and refuses loudly when text would be lost.

Two kinds of input, both first-class:

- **Native Word:** heading styles, real numbered lists, maybe NOTE/CAUTION styles.
- **Acrobat export:** few or no heading styles, direct formatting (bold, font size), running headers and footers baked into the body as ordinary paragraphs, text boxes, hand-typed numbering ("1." typed as text), and tables used for layout.

**Text fidelity beats layout fidelity.** A controlled manual that silently loses a sentence is worse than one with a plain-looking heading. The completeness report is the safety rail; build it first.

### 3. Walk the model into leaves (`server/ingest/docx.ts`)

Produce `{ leaves: { leaf: CatalogLeaf; doc: JSONContent }[]; dropped: DroppedLine[]; figures: FigureRef[] }`.

- **Leaf boundaries.** These paragraphs start a leaf:
  - `Section N: Title` and `Appendix X: Title`
  - **lettered sections**, any case, colon optional, title on the same line or the next: `SECTION A:`, `SECTION E THRU I`, `APPENDIX C`. The section's page-label prefix is what its pages print (`A`, `E-I`, `AC`, `AD`). Keep it as printed (lock: `lep-page-ledger.md`, Ingest checklist step 5); do not derive `AC` from `C`.
  - the front-matter titles `extractSections` knows (Record of Revision, List of Effective Pages, Table of Contents, Source of Training Document, …), plus **each front-matter entry the book's own TOC lists with a roman page** (Table of Bulletins, Administration, Introduction, …)
  - the **Bulletin** pages (see O1)
  - a heading style whose text matches any of these patterns
  - **Skip TOC entries**: lines with a page reference (`… 1-1`, `\t1-1`, `… A-1`, `… E-I-1`, `… AC-1`, roman numbers, dot leaders), plus everything between the TOC title and the first body section.
  - Match each body leaf to the classified section by number or letter, so `start`/`lep_start` come from classify.
- **Pagination regions.** Set the manual's `pagination` from what the book prints (lock: `lep-page-ledger.md`, Ingest checklist steps 2–3):
  - for the fixture: `lep`, with a `letter-cover` region (`a`, `b`), a `roman-front` region (upper-case as printed), and a `section-page` body whose prefixes may be more than one letter (`E-I`, `AC`).
  - Copying the LEP's rows into the page ledger (step 4) is **not** this task. Say in the PR what it would need.
- **Managed leaves** (ROR, LEP, LES, TOC; `inferManagedKind`): write the leaf with its managed frontmatter and an **empty** body. Revdesk generates those pages. Their source text is excluded from the coverage count and listed in the report as "managed, regenerated."
- **Running headers and footers.** Before walking, drop paragraphs that are short (≤ 80 chars) **and** either:
  - match a page label (`^\d+-\d+$`, `^[A-Z]{1,2}(-[A-Z])?-\d+$`, `^[ivxlc]+$` in either case, `^Page \d+( of \d+)?$`) or the revision footer (`Revision \d+ \d{2}-[A-Za-z]{3}-\d{4}`), or
  - are only the blank-page marker ("Intentionally left blank", any case).

  Record every dropped line (text + count) for the report. **Never drop a line longer than 80 chars or one inside a table.** A line that merely repeats is **kept**: list short lines repeated ≥ 3 times in the report as repeated lines for the author to clean up. (Changed in review of #34: a "repeats ≥ 3" drop removed real sentences and form labels in the corpus, and Acrobat puts running heads in header parts anyway.)
- **Headings** (shape oracle: `loremBody()` — H1 = the leaf title, H2 = `N.N` / `N.N.0` heads, H3 = `N.N.N`, H4–H5 deeper):
  1. Word style `Heading 1..5` / `Title` → that level (H1 only for the leaf title line).
  2. Otherwise, a paragraph is a heading when its text matches `^(\d+(\.\d+)+)\s+\S` **and** it is ≤ 120 chars **and** (all runs bold **or** font size > the document's median body size). Level = number of dot-separated parts (`1.2` → H2, `1.2.3` → H3, …), with a trailing `.0` not counting as a level (`1.1.0` → H2).
  3. A numbered line that fails the bold/size test stays a paragraph. **Do not guess headings from bold alone.**
- **Paragraphs:** runs → text nodes with `bold` / `italic` / `underline` marks (the marks `parseInline` round-trips). Tabs → a single space. Line breaks inside a paragraph → a space. Hyperlinks → their text.
- **Lists** (**after T3.3 lands**):
  - `numbering.isOrdered` → steps (`orderedList`), nested by `numbering.level` up to depth 5.
  - Unordered → `bulletList`, nested the same way.
  - Hand-typed numbering from Acrobat (`^\d+[.)]\s` as text, no `numbering`) in a run of ≥ 2 consecutive paragraphs → steps, with the typed number stripped.
  - Hand-typed bullets (`^[•·▪○◦-]\s`) → bullets.
- **Callouts:** a paragraph (or a single-cell table) whose text starts with `NOTE`, `CAUTION`, or `WARNING` followed by `:` or a line break → `note` / `caution` / `warning` with the label stripped. A Word style named `Note`/`Caution`/`Warning` maps the same way.
- **Tables:** first row → header row. Each cell's paragraphs are joined with a space, because pipe tables are inline-only. Count every cell that held more than one paragraph or a list as **flattened** in the report. Merged cells → repeat the text in each spanned cell and count it. A **single-cell table that isn't a callout** is a layout box: unwrap it into ordinary blocks.
- **Figures** (**after T3.1 lands**): `image.read()` → `writeFigure(dataRoot, manualId, bytes, ext)` from `server/figures.ts` → a `figure` node.
  - Caption: the following paragraph if its style is `Caption`, else `altText`, else empty.
  - `emf`/`wmf` and other unsupported types: no conversion in this task. Emit the contract's text placeholder and list it in the report.
- **Never concatenate Markdown.** Build `JSONContent` and call `serializeBody()` from `src/schema/markdown.ts`. Then `parseBody(serializeBody(doc))` must equal `doc` for every leaf; assert this in the import and fail with exit 5 naming the leaf if it doesn't.

### 4. Completeness report (`server/ingest/report.ts`, new). Build this first.

- [ ] Normalize: NFKC, lowercase, strip punctuation, split on whitespace.

- [ ] Coverage is multiset overlap / source count, **overall and per leaf**. Gate: overall ≥ 0.98 and every leaf ≥ 0.95. Below the gate → `RepoError(2, …)` that names the worst leaves, **before anything is written**. `--accept-gaps` (CLI) / `accept_gaps: true` (HTTP) lets it through.
- [ ] The report also lists:

  - managed leaves regenerated
  - flattened table cells
