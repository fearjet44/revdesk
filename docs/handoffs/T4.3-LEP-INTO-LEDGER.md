## Goal

This is on the **critical path to dogfood (D1)**. The operator's GOM is an LEP book. T2.2 brings its text in, but the page ledger it writes is wrong. Importing the practice fixture (`fixtures/ingest/samples/foobar-gom-practice.docx`) into a temp library gives today:

| Leaf | Ledger today | Why |
|---|---|---|
| Cover | scheme `section-page`, slot `a` | a cover letter isn't recognised as `letter-cover` |
| GOM Bulletin No. 1 | `chapter-page`, slot `1-1` | `inferStart` reads the `-1` at the end of the leaf id |
| Transmittal Sheet | `section-page`, slot `1-1` | `firstSlot` falls back to `1-1` |
| Table of Contents, LEP | `roman-front`, both slot `i` | no start; lower-case default; two leaves share one slot |
| Section E-I | letter `E`, slot `E-I-1`; the next slot would be `E-2` | `letterForLeaf`, `nextSlot`, `slotFamily` read only one letter |
| Appendix C, D | letter `C`/`D`, slots `AC-1`/`AD-1` | the letter comes from the title; the book prints `AC`/`AD` |
| Every leaf | one page each; `lep_slots: []`; `lep_inferred: true` | the LEP's rows are never copied (lock step 4) |

The fixture's LEP is a table with two column-sets per row: **SECTION | PAGE(S) | DATE OF REVISION | REVISION NUMBER**.

- **SECTION** names the group a page belongs to: `TITLE`, `TOB`, `INST`, `ADMIN`, `SECTION A`, `SECTION E- I`, `SECTION P`, `APPEND C`, `APPEND D`. It is printed only on the first row of each group.
- **PAGE(S)** spellings: `A`/`B` for the cover, upper-case roman for front matter, `A-n`, `E-I-n`, `P-n`, `AC-n`, `AD-n`.
- **REVISION NUMBER** is a word: `ORIGINAL` or `ONE`.
- **Known faults in the source:**
  - One page cell is a typo: `E-1-2`, between `E-I-1` and `E-I-9`.
  - One revision cell is a typo: `ONEL`, on the first cover page.

The book is cut down, so the page runs have gaps (`A-1, A-3, A-10, A-11`). That is fine; copy what is listed.

## Decisions (planner; do not reopen)

1. **Copy the LEP.** When the source has an LEP, every row whose page cell parses becomes a ledger page on exactly one leaf. That page keeps the slot as the LEP prints it and the revision from its own row. Write `manual.yaml` `lep_slots` (in LEP order) and set `lep_inferred: false`. **No slot may belong to two leaves.**
2. **Spelling follows the LEP** (lock step 5: "keep what the book already prints"). The cover slots are `A` and `B` as the LEP lists them, even though the cover pages print `a`/`b`. Write the cover region's `slots` and the cover leaf's `lep_start` the same way. Roman case is kept, so overflow after `XIV` is `XV` and after `xiv` is `xv`.
3. **Multi-part prefixes are one prefix.** Page labels match `^[A-Z]{1,2}(-[A-Z])?-\d+$`, the regex from T2.2. For `E-I-9` the prefix is `E-I`; for `AC-4` it is `AC`.
   - The ledger leaf's `letter` is the whole prefix.
   - `nextSlot`, `firstSlot`, `slotFamily`/`slotRank`, `schemeForLeaf` and `letterForLeaf` all treat it as one unit.
   - **Single-letter sample books must behave exactly as before.** Existing `scripts/ledger-check.ts` cases stay unchanged and pass.
4. **Revision words.**
   - `ORIGINAL` is revision 0; `ONE`, `TWO` … `TWENTY` and digits are that number.
   - A page with revision 0 shows **`Original`** in the LEP rows and the page footer. Use a new page-revision formatter for those two places; `formatRevNumber` stays as it is for everything else.
   - A revision cell that doesn't parse (the `ONEL` typo):
     - if the row's date equals the book's effective date, use the current revision
     - otherwise, hold the row
     - report it either way
5. **Rows that don't fit are held, not guessed.** A page cell that doesn't match the page-label regex or the book's regions (the `E-1-2` typo) is not copied. The import report lists held rows, with the reason, for the operator. The import still succeeds.
6. **A leaf with no page in the LEP and no start from the source is unpaginated.**
   - That is the bulletin and the transmittal sheet in the fixture.
   - It gets scheme `none`, no slots, and no LEP rows. Never invent `1-1` or `i`.
   - Rendering gives it pages with no slot. Its footer is the fallback that `footerLabels` already has (revision and book). It doesn't renumber or shift the slots of any other leaf.
7. **Ownership inside a SECTION group follows leaf starts.** The LEP's group label is coarser than Revdesk's leaves: `ADMIN` spans Administration, Introduction, Table of Contents, LEP, ROR and GOM Administration.
   - Within a group, a slot belongs to the leaf with the greatest start that is ≤ the slot, as `slotOwners` does today.
   - Use the group label to bound the run. A slot never crosses into a different SECTION group's leaf.
   - Some leaves inside a group's run have no start; in the fixture, the managed TOC and LEP do. Do not guess their pages. Leave them unpaginated as in decision 6.
   - List them in the import report under **page start unknown**, so the operator can set `lep_start` in that leaf's frontmatter. When `lep_start` is set later, the next render must give that leaf its slot from the start, not from a default.
8. **Books without an LEP don't change.** A `.docx` with no LEP keeps today's behaviour for its control surface. Books with `lep_slots` from a text or PDF classify, and the sample `data/` library, ledger as before. `rev-only` books never get slots.

## Do not

- Change the identity rule: the slot is the identity, never the PDF page index.
- Rename or renumber slots to a house style. Don't "fix" the `E-1-2` typo; hold it.
- Guess a start for a leaf the source doesn't place. Report it.
- Add a date column to the ledger or the LEP output. The LEP's dates are read only to resolve a bad revision cell. A per-page revision date is a separate task.
- Change `formatRevNumber` output, the overflow dagger rules, or `rev-only` / `les` behaviour.
- Commit anything from `corpus/` or paste corpus text into the PR, tests, or comments. Corpus results are numbers only. Don't read `corpus/foobar-gom-practice/`.
- Touch the sample `data/` library except through tests that copy it to a temp dir.
